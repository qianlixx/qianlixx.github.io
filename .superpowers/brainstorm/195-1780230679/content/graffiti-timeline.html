🖌️ 第三节：涂鸦时间线 — 核心视觉

那条贯穿全页的 graffiti 线，是页面的脊椎

技术实现方案

SVG 喷漆线（主）
• 用 SVG 绘制一条 S 形蜿蜒 路径（不是直线，不是直角）
• 3 层叠加制造喷漆感：
  — 第 1 层：粗线 4px，opacity 0.25，带 feTurbulence filter 喷溅效果
  — 第 2 层：细线 1.5px，opacity 0.12，x 偏移 -3px
  — 第 3 层：最细 0.5px，opacity 0.06，x 偏移 +5px
• 描边颜色 从棕渐变到红到金到橙到蓝到紫（匹配每个 phase 的主题色）
节点 + 滴落效果
• 每个 phase 在线上有一个 圆节点（dot），直径 20px
• 节点周围有 glow 光晕（大 3 倍，blur）
• 节点下方有 油漆滴落（drip）——一条 2px 宽的竖线，底部渐隐
• 滴落长度每个 phase 不同，像真实的喷漆流动

重要细节

1.
描边动画
进入视口时线从顶部逐渐画下来（stroke-dashoffset）
2.
节点弹入
对应的 phase 可见时，node 缩放弹入 + glow fade in
3.
滚动联动
滚动时 graffiti 线实时「描画」进度

颜色 vs 阶段对应：
棕 (郫县少年) → 橙 (横空出世) → 红 (Beef) → 金 (HB 走向世界) → 橙 (黑马王子) → 蓝 (高产期) → 紫 (乐透人生)
