# 多巴胺配色方案 · 日落霓虹

## 概述

将个人网站从暗色琥珀色系改造为高饱和度、高对比度的「多巴胺」配色方案。每个板块拥有独立的主色，共用金黄色点缀色。

## 配色映射

| 板块 | 背景色 | 主色 | 点缀色 |
|------|--------|------|--------|
| **关于我** | 深暖褐 `#1a0a04` | 活力橙 `#FF6B35` | 金黄 `#FFD166` |
| **摄影** | 深暗绿 `#041a14` | 霓虹青绿 `#06D6A0` | 深海蓝 `#118AB2` |
| **电影** | 深酒红 `#1a0408` | 荧光粉 `#EF476F` | 金黄 `#FFD166` |
| **音乐** | 深海蓝 `#04101a` | 明亮靛蓝 `#118AB2` | 青绿 `#06D6A0` |

## 全局共用元素

- **导航指示器**: `#FFD166` 金色
- **按钮 / 链接悬停**: `#FFD166` 金色高亮
- **自定义光标**: 金色半透明环
- **文字层级**: 主文 `#e8ddd0` / 次文 `#a09088` / 弱文 `#6a5c54`（暖灰系，适配所有色块背景）
- **标题 / 姓名**: 各板块主色（如 #FF6B35、#06D6A0 等）

## 摄影区特殊处理

摄影板块每张照片的对应文字按钮保留原有自定义配色（pi-0 ~ pi-5），不强制统一，保持每张照片的个性。

## 电影区

电影区主色为荧光粉 `#EF476F`。选中卡边框、标题文字、评分星级均使用粉色系。未选中卡片保持低饱和度灰调。

## 背景渐变叠加

每个板块在底色之上保留原有径向渐变光晕效果，但光晕颜色改为对应主色的半透明版本（opacity 0.08-0.15），增强多巴胺氛围感。

## 修改范围

仅 CSS（`<style>` 块内），不动 HTML 结构和 JS 逻辑。

## 涉及文件

- `index.html` — CSS 变量、section 背景色、导航指示器、按钮样式、光标颜色
